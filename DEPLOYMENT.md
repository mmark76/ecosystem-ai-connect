# Deployment Boundary

No deployment is configured or authorized. Ecosystem AI Connect currently selects the `LOCAL_ONLY` infrastructure profile and has no hosted service, website, dashboard, Cloudflare project, DNS record, runtime account, or production environment.

Future package publication, provider communication, and a hosted backend are separate decisions. A hosted service requires an approved move to `SHARED_INFRASTRUCTURE` or `DEPLOYED_SERVICE` with a project-specific deployment, rollback, recovery, and security plan.
