# Security Plan

## Status and authority

[Ecosystem Security — The Shield](../../foundations/shield/README.md) remains authoritative at the revision in [`FOUNDATION_VERSIONS`](../../FOUNDATION_VERSIONS). This is a project-owned assessment for a local SDK. `AIC-SCOPE-002` implements a bounded OpenAI API-key connector; it does not verify a provider account, live credentials, production operation, hosting, or OAuth authorization.

`APPLICABLE_NOW`, `APPLICABLE_WHEN_IMPLEMENTED`, `NOT_APPLICABLE`, and `NEEDS_DECISION` describe applicability, separately from the current adoption or verification status. `NEEDS_DECISION` is not an owner assignment. `NOT_YET_AVAILABLE` never represents completed evidence.
